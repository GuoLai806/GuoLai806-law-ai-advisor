# 用户版：真实软件依赖测试资料

已准备 27 份公开软件包的版本资料和 30 道初步问题，供后续接入真实检索系统。资料展示 Express 不同版本及其下游依赖，能检验跨文档找路径、比较版本和处理证据不足。

这批资料只覆盖选定的固定版本关系。有些依赖需要安装时才确定具体版本，所以不能用它声称查全了所有依赖；现有跨文档问题也只要求找到一条有证据的路径。正式验收前还需补齐适合完整闭包的语料与独立核对的题目，并在真实系统中运行。时间题目前是版本比较，不证明某个日历日期的生效状态。

来源、许可、数据和验证命令见[资料说明](README.md)；执行细节见 [AI 版](PLAN-FOR-AI.md)。本目录是主任务的独立数据模块，集成和 GitHub 同步由主任务负责。
