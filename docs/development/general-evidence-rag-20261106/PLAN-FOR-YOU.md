# 通用 Evidence RAG 本轮交付

本轮把早期法律RAG重构成通用证据检索核心，法律规则保留为可选配置。可以导入JSONL、文本或PDF，按版本保存文档、段落、原文位置和哈希；组合词法召回、OpenViking向量召回和重排，按完整证据单元控制回答上下文。默认共享公开语料，身份和会话由服务端绑定。

质量优先配置选择 BGE-M3 召回和 Qwen3-Reranker-4B 重排。选择来自相同32条公开验证查询的四组对照，Qwen重排平均指标最高；差值区间仍跨零，不能宣称确定优于另一个模型。其每题重排中位约17.2秒，BGE重排约1.68秒；BGE重排保留为低延迟备选。Qwen召回没有显示出相应收益，完整语料编码反而约慢十倍，因此不作为默认。

主要质量依据是英语科学文献检索 SciFact：完整5,183篇文档，先在官方train冻结32题选模型，再冻结配置运行官方300题test。测试的候选排序使用本机精确余弦参考后端和产品共享排序代码；真实OpenViking、HTTP、云模型SSE是另外的小样本集成证据。它们不是同一层的测量，也不代表最终问答准确率或其他语言/领域的普遍效果。完整结果以基准报告和最终DELIVERY.json为准；正式test已完成，最终结果见下方更新。

实际生成默认需要匹配的tokenizer和聊天模板、模型窗口与输出余量，以及一般问题独立标定的重排阈值。缺组件或缺标定时可展示检索资料，拒绝把系统标成完整问答就绪。近似字节预算只作为明确允许的通用互操作选项，不是精确token或生产校准。引用检查只核对ID结构，主张的语义支持仍标为未验证。

代码回归、真实模型和引擎集成都保留了失败及修复记录。重排得到最高分的段落现在与交付段落一致；缺段落归属时清除分数并降级；回读时验证正文/段落哈希，截断输出和无效引用不会作为完成回答保存。源码含评测日志共105项回归通过，wheel已在独立环境安装并验证。

部署前需要使用自己的模型、凭据和数据目录。仓库不包含模型权重、数据集原始语料或私人配置；现有静态网页未适配新鉴权/SSE。容器目前只验证配置，未在目标主机部署。法律原文仍待正式来源审核，不因开发测试被标为已人工审核。迁移先保留旧版本和原索引，新版本校验完后按预期revision切换；回退保留新证据，让活动指针回到仍可用的旧revision，不盲目重发未知写入。详细执行见 [AI版](PLAN-FOR-AI.md)。

发布顺序：先保留已推开发分支，完整验收及证据提交后重新核对origin/main；可安全快进时更新主线，保留开发分支，不force覆盖他人工作。实际远程状态以最终交付记录为准。

长文范围：当前通用dense单元为完整输入文档，超过模型窗口须上游准备有来源的短单元，不能把OpenViking估算截断当分块。SciFact全部序列化文本通过默认4096估算不变检查，但任意长PDF/复杂版面/OCR未完成质量验收。参考examples输入策略说明。

导入语义：每次ingest形成完整revision快照，新增文件不自动合并活动语料；应准备合并后的完整输入再创建新版本。完整命令见examples/README。

最终验收更新：完整官方300题、零执行故障；nDCG@10 0.794175（产品词法0.668854）、Recall@20 0.935889（0.836556）、MRR@10 0.762501（0.635099），NIST -c -q逐题与总体核对通过，冻结source前后相同。真实选定Qwen重排、公共BGE端点、既有OV合成索引和云模型SSE通过小样本互操作；预算为显式近似字节模式，claim_support仍not_verified。正式全文排名及journal见generic-benchmark-20261106/RESULTS.md。
