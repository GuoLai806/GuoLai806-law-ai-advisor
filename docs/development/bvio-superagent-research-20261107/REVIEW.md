## 2. 技术质量与执行边界

RAG 规格保留真实 OpenViking find、BM25、RRF、Qwen 和版本正文，优先把 HTTP 生命周期作为独立因素验证。共享客户端的 ownership、关闭、取消、deadline、配置与作用域边界已写明；测试必须走实际生产实现与真实服务，不能用 MockTransport 计时证明网络收益。

探索入口和正式证据分开。`ExploreBundle` 不能直接变成可生成答案的 `EvidenceBundle`；深读绑定同 revision、正文 hash 和原文指针，必要深读计入完整请求等待和用量。类型、时间、来源过滤须同时作用于语义与关键词两路。更新 accepted、正文对账、向量可见、activated 分开，未知写入结果不盲重放。

GCode 方案准确区分普通 AgentTool 与技能 fork 路径。普通路径已有父权限上限、预算和 hook；技能 fork 另建 Agent 时没有完整传递这些契约，不能据此说全产品没有权限。`full` 上下文逐条截断、LoadSkill 不按 mode 分派、动态扩展导入可执行代码等事实均有固定源码和 AST 依据。G0 统一入口是新控制层前置依赖，权限修复异常时应禁用有问题的 fork，不能回退为无 checker。

SuperAgent 采用持久任务控制层的思路，同时保留 GCode Executor。规格区分 Ticket、Assignment、Run 与业务完成；SQLite/effects、跨库启动对账、旧执行者代次、陈旧报告、人工 stop、进程核实与工作树保留都有明确边界。原型外部发送与本地 receipt 之间存在 crash 窗口，报告没有声称外部 exactly once；应用层工作目录与权限没有冒充操作系统沙箱。首版本机明确请求、默认 disabled，不开启外部监听、评论、合并或推断接单。

测试协议区分 T1 连接阶段、T2 个人真实完整用户路径、T3 企业原样系统和十个 Agent 工程场景。正式题号与参数冻结、失败进入分母、AB/BA 顺序、配对统计、时钟/睡眠检查、原文与会话回读、所有 attempt 用量与 unknown 保留已写明。T2 两组固定使用已验可选 `grounded_json + grounded_evidence`，不改变产品 text 默认。协议正确区分可固定的本地 embedding/reranker 权重与不可视作固定权重的云 alias；新模型或新配置不能混作历史同模型提升。30 题、6 个机制场景和 10 个工程场景没有混用分母，也没有被当成行业榜单。

## 3. 已关闭的确定问题

### R-1 / P2：RAG 既有接口命名空间写错

- **位置：** `PLAN-FOR-AI.md:52` 的 C2 接口规格。
- **原触发：** Agent 按原文新增 `/v1/explore` 并“保留” `/v1/retrieve`、`/v1/chat/stream`。
- **依据：** 固定个人源码 `evidence_rag/api.py:173` 为 `/api/v2/retrieve`，`:313` 为 `/api/v2/chat/stream`；原方案所写两个 `/v1` 既有接口不存在。
- **影响：** 会制造不一致入口，不能按真实既有契约开发和验证。
- **建议与修复：** 新增 `/api/v2/explore`，保留 `/api/v2/retrieve` 与 `/api/v2/chat/stream`。已复读修后实际字节，**关闭**。

### R-2 / P2：企业完整用户链的桥接成本归属含糊

- **位置：** `BENCHMARK-PROTOCOL.md:57` 的 T3 公平比较句。
- **原触发：** 企业预览工具通过独立桥接完成生成、引用与回读时，原文只写桥接成本“记入 B”；其他对照又复用 A/B，可能把企业成本归到个人候选或排除。
- **影响：** 将造成完整等待和用量的不公平归因，影响企业系统性能结论。
- **建议与修复：** 明确“计入企业候选的完整请求等待与用量”。已复读修后实际字节，**关闭**。
