# 模型评测的精确源码快照

v2 是四组候选模型比较的11个冻结源文件；v3修复正文完整性与重排获分段归属；v4只改变评测逐题日志/输出预检，不改变产品打分。每个版本包含与其freeze逐字节匹配的全部source_sha256文件，未重新生成旧成绩。

复现旧版本时从最终仓库提交建立独立副本，将对应快照覆盖到相同相对路径，验证SOURCE-SHA256和freeze，然后在固定模型环境从该副本根运行benchmarks.run_product；数据/模型/向量缓存置于库外，使用新的输出路径。不能直接在当前开发目录覆盖源码并与运行中的测试混用。

这些快照仅覆盖冻结清单，不是所有传递依赖的签名封装；Python和库版本另由freeze固定，模型revision和语料hash保留。v2-v3向量缓存复制有逐条输入等价及byte hash审计，独立CPU分数回放不冒充真实推理；v3和v4已另做真实选定模型32题。
