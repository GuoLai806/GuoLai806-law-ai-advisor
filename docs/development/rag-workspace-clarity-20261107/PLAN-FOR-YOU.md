# RAG 页面现在怎么用

现在打开页面就能查，不需要再填令牌。页面从上到下分成三块：**检索到的内容、AI 最终答案、本次耗时**。你能先看系统找到了哪些资料，再看 AI 根据这些资料得出了什么结论，最后看这次等了多久。

[打开本机页面](http://127.0.0.1:19447/) · [同决定 AI 版](PLAN-FOR-AI.md) · [实际验证记录](RESULTS.md)

输入问题后，点“检索并生成答案”就会走完整流程；点“只检索资料”则只找资料，不调用生成模型。每条资料有标题、段落预览和“查看完整原文”，问答检索的段落也可展开。答案完成并经过现有检查后才展示，支持、矛盾、证据不足都用中文标签提示。引用摘录可以单独打开核对；摘录存在于原文，不等于所有推理都一定正确。

耗时分成“资料检索等待”“AI 生成与核验”“本次总等待”。这是你点击到页面完成的等待，包含网络、排序和核验。只检索时会明确显示没有请求生成；停下来读资料的时间，不会混进下次问答的计时。停止或改题也不会把旧答案当成本次结果。

去掉令牌输入只针对明确开启的本机演示服务，沿用已有的普通演示身份。密钥没有放进页面；脚本仍能使用原有 Bearer 接口，错误令牌、跨来源请求和错误主机访问仍被拒绝。默认服务仍需要认证，当前没有公网发布。

真实 OpenViking、当前模型、资料版本和引用检查继续使用原来的配置。这轮主要改善看结果的方式。451 项 Python 检查、10 项前端检查、独立复审、构建安装，以及真实网页问答、预览、原文、停止和改题都已完成。实际一次问答检索 18.81 秒、生成与核验 9.28 秒、总等待 28.09 秒；这只是一题的体验记录，不证明准确率提高或整体提速。

新版本已在这台机器运行，页面保留供你体验。用户本人是否满意还等你实际使用；GCode、SuperAgent、MyAgent 和简历正式改写继续留在[待办](../rag-exploration-20261107/TODO.md)。详细交付与回退见[交付记录](DELIVERY.md)，GitHub 同步状态以其中的远端回读记录为准。
